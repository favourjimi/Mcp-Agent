## Current Milestone: v0.4

The current work is persistent local memory. The prototype stores the user's
name in a local JSON file and can display stored entries with the `remember`
command. Custom fact capture and retrieval are the next milestone, v0.5.

## Before Launch

The project is still pre-launch. Continue development through the planned
milestones and verify the assistant's behavior before making a first release.
